# Projects

A collection of my main projects, each in its own repository.

## 🎮 Action Platformer Game (C++)
Repo: **C-game**
A 2D platform game built in C++ using the SGG library, featuring level progression, AABB collision detection, enemy hazards, and a health system.

https://github.com/Fragiski/C-game

## 🎰 Distributed Betting System (Java)
Repo: **Distributed-Betting-System**
An end-to-end distributed gaming system with an Android frontend and multithreaded Java backend, using TCP sockets, MapReduce, and dynamic hashing.

https://github.com/Fragiski/Distributed-Betting-System

## 🏛️ Distributed Auction System (Java)
Repo: **Distributed-Auction-System**
